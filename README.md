# 紙町活版所の無料ツール

登録不要・無料で、ブラウザだけで使える小さな道具です。入力した内容や選んだファイルは、お使いの端末の中だけで処理します。

**サイト: https://sulla-bluefelix.github.io/kamimachi-tools/**

| ツール | できること |
| --- | --- |
| [旅行の割り勘・立替精算](https://sulla-bluefelix.github.io/kamimachi-tools/warikan/) | 誰が誰にいくら払えばいいかを1円単位で計算 |
| [旅行の持ち物チェックリスト](https://sulla-bluefelix.github.io/kamimachi-tools/packing/) | 人数と泊数から持ち物の個数を自動計算、印刷 |
| [変拍子・ポリリズム メトロノーム](https://sulla-bluefelix.github.io/kamimachi-tools/metronome/) | 3+2+2 などのまとまりや 3対2 をその場で鳴らす |
| [SRT字幕ファイル作成](https://sulla-bluefelix.github.io/kamimachi-tools/srt/) | 台本から字幕のタイミングを振ってSRTを書き出す |
| [迷路メーカー](https://sulla-bluefelix.github.io/kamimachi-tools/maze/) | 道が1本の迷路を自動作成、答えつきで印刷 |
| [値札・プライスカードメーカー](https://sulla-bluefelix.github.io/kamimachi-tools/nefuda/) | 即売会・フリマ用の値札をA4に面付けして印刷 |
| [画像からクロスステッチ図案](https://sulla-bluefelix.github.io/kamimachi-tools/cross-stitch/) | 画像を減色して記号つきの図案と色一覧に |
| [PDF比較](https://sulla-bluefelix.github.io/kamimachi-tools/pdf-diff/) | 新旧2つのPDFの違いをページごとに表示 |
| [TRPGダイスロール](https://sulla-bluefelix.github.io/kamimachi-tools/dice/) | 2d6+3 などのダイス式とCoC技能判定 |

有料のオフライン版・印刷用の道具は [BOOTH](https://kamimachi-press.booth.pm/) で頒布しています。
