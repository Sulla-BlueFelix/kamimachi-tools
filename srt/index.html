SRT字幕ファイル作成ツール

台本を貼ると字幕のタイミングを自動で振り、SRTファイルとして書き出せます。手入力や既存の.srtの編集、時刻のずらしにも対応。登録不要・無料で、データはこの端末の中だけで処理します。

1. 字幕のもとを入れる

表示時間は「文字数÷1秒あたりの文字数」を、最短〜最長の範囲に収めて決めます。ニュースの読み上げは1分間に約300字（1秒あたり約5文字）と言われます。話す速さに合わせて調整し、細かい時刻は下の一覧で直してください。

ここにファイルをドラッグしても読み込めます。文字コード（UTF-8／Shift_JIS／BOM付きUTF-16）は自動で判別します。

読み込むと、今の一覧は置き換わります（「元に戻す」で戻せます）。番号の抜けや余分な空行、ミリ秒の前がピリオドの時刻もそのまま読み込めます。

2. 字幕の一覧

一覧をすべて消しますか？

時刻は「00:00:01,500」でも「1.5」（秒）でも入れられます。本文の中で改行すると、字幕の中の改行になります。

3. 時刻をまとめてずらす

プラスで後ろへ（遅く表示）、マイナスで前へ（早く表示）。1秒＝1000ミリ秒です。0秒より前になる時刻は0秒にそろえます。

4. チェック

全角1文字を1、半角1文字を0.5として数えます。終了が開始より前、前の字幕との重なり、空の本文、長すぎる行などを一覧にします。

5. 書き出し

.srt

文字コードはUTF-8、改行はCRLF（Windows形式）で書き出します。

使い方

  1. 台本があるときは「台本から作る」に1行1字幕で貼り、「一覧を置き換えて作る」を押します。既存のSRTを直すときは「SRTを読み込む」から。
  2. 「字幕の一覧」で時刻と本文を直します。時刻は 1.5 のような秒でも入れられます。
  3. 動画とずれているときは「時刻をまとめてずらす」を使います。「チェック」に注意が出たら、番号のボタンで該当の字幕へ移動して直します。
  4. 「.srtをダウンロード」で保存し、動画編集ソフトやYouTubeに読み込みます。

SRTファイルとは（書式の例）

SRT（.srt）は、字幕の表示時刻と本文だけを書いたテキストファイルです。1つの字幕は次の4つでできています。

  1. 通し番号（1から順に）
  2. 表示時刻「開始 --> 終了」。時:分:秒,ミリ秒 の形で、時・分・秒は2桁、ミリ秒は3桁。ミリ秒の前はカンマです。
  3. 本文（1〜2行。改行はそのまま画面での改行になります）
  4. 空行（次の字幕との区切り）
1
00:00:01,000 --> 00:00:03,500
こんにちは。

2
00:00:04,000 --> 00:00:06,200
字幕の中で改行すると
2行で表示されます。

よく似た WebVTT（.vtt）形式は、先頭に「WEBVTT」と書き、ミリ秒の前がピリオドになるなどの違いがあります。

よくある質問

作ったSRTファイルはどこで使えますか？

YouTube Studioの字幕のアップロード、VLCなどの動画プレーヤー、Premiere ProやDaVinci Resolveなどの動画編集ソフトで読み込めます。動画と同じ名前（例：movie.mp4 と movie.srt）にして同じフォルダーに置くと、自動で字幕を表示するプレーヤーもあります。

書き出したSRTが文字化けします。

このツールはUTF-8で書き出します。古いソフトで文字化けするときは、「先頭にBOMを付ける」にチェックして書き出し直してください。読み込みはUTF-8・Shift_JIS・UTF-16（BOM付き）を自動で判別します。

字幕1枚あたり何文字くらいが読みやすいですか？

映画の字幕では「1秒4文字・1行13〜16文字・2行まで」がよく使われる目安です。話し言葉に合わせる動画の字幕ではもう少し多くても読めますが、1行が長すぎると画面の端まで広がるので、チェック欄の「1行の文字数の目安」で確認できます。

時刻はどの形式で入力できますか？

「00:00:01,500」のほか、「1.5」（秒）、「1:02.5」（分:秒）、「0:01:02.5」（時:分:秒）でも入力できます。欄から離れると、SRTの形式（時:分:秒,ミリ秒）に自動でそろえます。

字幕全体が動画とずれています。

「時刻をまとめてずらす」で、ミリ秒単位で全体を前後に動かせます。途中から（例：12番以降だけ）ずらすこともできます。0秒より前になる時刻は0秒にそろえます。

入力した字幕はどこかに送信されますか？

送信されません。読み込んだファイルも含めてブラウザの中だけで処理し、作業内容はこの端末に自動で保存されます。
